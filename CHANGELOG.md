# Release history

## 1.1.0 — 2026-11-19

Founder-friendly guided experience:
1. A short first reply explains how to answer and ask for help.
2. One useful question at a time by default, with everyday language.
3. Distinct responses to confusion, undecided choices, missing data, deferral and pause.
4. Free-form founder answers become clear summaries without requiring polished writing.
5. An early, explicitly partial starter context shows progress.
6. Maturity-aware questions avoid asking idea-stage founders for nonexistent operating metrics.
7. A simple three-part journey, scoped grouped reviews and saved resume guidance.

Arabic and English opening copy, a starter-context template, beginner scenario fixtures and packaging checks are included. ChatGPT's standalone project instructions carry the same core behavior.

The build now produces both installation ZIPs and versioned checksums from release.json. Existing v1.0.0 downloads and company bundles remain compatible; the company schema is still 1.0.0. The skill ID remains ai-company-context-architect.

## 1.0.0 — 2026-11-18

First public release: 12 stage protocols, eight schemas, nine templates, Build/Audit/Update/Export modes, platform adapters, and 38 local contract tests.
